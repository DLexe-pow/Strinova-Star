# Strinova Star

卡拉彼丘（Strinova / Calabiyau）录像处理工具：**认人、找击杀、切高光、录屏**，都做成界面按钮，点就行。

- **认双方阵容**：翻 Tab 计分板读昵称 + 头像认角色；没开 Tab 就用顶部阵容条认出 10 个角色
- **找我的击杀/击倒**：扫左上角播报，只挑你自己的那几行，名字会对齐计分板里的昵称
- **分回合**：按 HUD 比自动切出每一小回合，点一下跳到那一回合
- **时间轴**：击杀/击倒标在进度条上，点一下跳到那一秒；支持滚轮缩放、拖选、聚焦
- **切高光**：按你设的前后秒数切片，重叠的自动并成一段，`-c copy` 不重编码
- **录制**：全局 / 手动，支持系统声音（WASAPI 环回）和麦克风分开成两条音轨，F9 开关

## 下载即用

到 [Releases](https://github.com/DLexe-pow/Strinova-Star/releases) 下最新的 `StrinovaStar-vX.Y.Z.zip`，解压后双击 `Strinova Star.exe`。

- 绿色版，不用安装；自带 Python 和 ffmpeg，解压目录别删子文件夹
- 运行数据在 exe 旁边的 `data\`（录像缓存、切片、日志都在这里），整个目录可以随便挪
- 首次启动会自动猜录像目录（`视频\NVIDIA\...` 或 `D:\game\NVIDIA\...` 里录像最多的那个），猜错了点「选文件夹…」换

## 从源码运行

需要 Python 3.13 和 ffmpeg。

```bat
pip install -r requirements.txt
python src\app.py          :: 起界面，默认 http://127.0.0.1:8765
python src\run_tests.py    :: 跑单测
```

## 素材（重要）

仓库里**只放代码、标定档和三个播报小图标**，不放游戏里的角色立绘 / 武器图标 —— 那些是游戏的版权素材。

缺图时「识别双方阵容」会提示模板目录为空。自己补：游戏里截图裁一下，按角色名放进对应目录（尺寸见 [ASSETS.md](ASSETS.md)）：

```
assets\characters\halfbody\<角色名>.png    224x320  透明底，取到胸口
assets\characters\portraits\<角色名>.png   128x128  头像
assets\characters\lineup\<角色名>.png      85x52    顶部阵容条那格
assets\characters\roster\<角色名>.png      52x34    计分板小头像
assets\weapons\icons\<武器名>.png          180x82
```

## 怎么用

1. 左上角选录像（或点「选文件夹…」换目录），点一下列表里的录像开始播
2. 点「识别双方阵容」→ 认队友和对手，结果按我方/对方两列排
3. 点「找出我的击杀」→ 扫整段播报，结果进「击杀 / 击倒」页签，进度条上也会标出来
4. 点「分回合」→ 按 HUD 比分切成小回合，点某一回合跳到它的开头
5. 设好「击杀前/击杀后」秒数，点「按秒数切片」→ 片段在「切片产物」页签，点一下直接在播放器里看（片段内也有时间轴）
6. 想一边玩一边录：设置页开「录系统声音」，选模式，点「开始录制」或在游戏里按 **F9**

## 常见问题

**认不出角色？**
先确认素材齐全（见上一节）。识别靠局内头像比对，计分板被阵亡红叉压住时认不出属正常，多翻几次 Tab 会投票合并。

**没开 Tab 能用吗？**
能，会自动用顶部阵容条，但只有角色没有昵称。

**录制黑屏？**
游戏要设成**无边框全屏**。独占全屏时会录到黑屏，这是系统截屏接口的限制。

**切片太慢/失败？**
检查 ffmpeg 是否可用（设置页「关于」里会显示用的哪个）；切片是 `-c copy`，关键帧对齐，起止点会有不到 1 秒的漂移。

**杀毒软件提示？**
软件会开全局热键、录屏、录系统声音，还可能被 SmartScreen 拦（没签名）。源码全在仓库里，可以自己编译运行。

**出错了怎么反馈？**
界面右上角出错时会有「导出日志」按钮（设置页也有），导出的 txt 里有版本、设置快照和完整堆栈，把它发出来即可。

## 系统要求

- Windows 10 / 11
- 录屏建议 NVIDIA 显卡（用 NVENC 编码，120 帧 2K 约 9 GB/小时）
- 硬盘留够空间：一小时全局录像约 9 GB，切片产物另算

## 隐私

- 只在本地读屏幕画面和录像文件，**不联网、不上传**
- 日志、缓存、切片全在 `data\` 里，删掉等于全部清空
