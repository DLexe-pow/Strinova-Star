## 踩过的坑（写进 README 了）

- **真值裁片不能带标注红框**：红框像素占 29.7%，把「白墨（绿发）」测成「米雪儿·李（金发）」。要从无标注原始帧重切。
- **模板不能用裁好的小头像**，要用半身立绘原图；跨域（2D 立绘 vs 3D 渲染）全局直方图到顶只有 19~20/20，白墨必然错。
- `cv2.imread/imwrite` 不认中文路径 → `np.fromfile + imdecode` / `imencode + write_bytes`。
- 这台机器的 python 是嵌入式版，忽略 `PYTHONPATH`；`unittest discover` 拿不到包，`run_tests.py` 逐文件导入，测试必须写 `TestCase` 类。
- `solve()` 行多于列时转置翻回曾写反（`IndexError`），现用 300 组随机矩阵与穷举对拍。

## 明天接什么

3. `scoreboard.py`：一帧截图 → 10 条「昵称 + 角色」，昵称走 rapidocr、角色走 `OrbMatcher`、10 人用 `assign()` 一人一角色。
4. 再往后：`detector.py`（中下战果横幅 + 左上播报）、`clipper.py`（无损切片）、`organize.py`（按对局编号归档）。

- 昵称里形近字（`猫窝` / `猫屋`）需要人工兜底，`roster/overrides.json` 是现成的修正层。
